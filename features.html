Everything in one app

Encrypted chat, a friends network and an AI assistant. All of it is in Fast Connect 1.1.

Multi-Layered Encryption

Every connection to a chat server is encrypted with AES-256. On top of that, broadcasts and private messages pass through several layers of the Vigenère cipher.

FastAI Desktop Assistant

A chat assistant powered by Google Gemini, with model switching. It can describe images (.jpg, .png, .webp), analyze video, generate images and produce audio.

Cloud Accounts

Register and log in securely. Passwords are stored only as salted, slow hashes, and chat servers verify who you are without ever seeing your password. Your profile and friends are saved to the cloud.

Friends & Requests

Search for connected users, send friend requests and accept the pending ones, all from the Users tab.

Private DMs & Broadcasts

Double-click a friend to open an encrypted one-on-one chat, or broadcast to everyone on the server.

Stable Networking

The TCP server and client send length-prefixed binary frames, and a multi-threaded server delivers the messages.

1
