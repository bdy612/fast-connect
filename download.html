Install in a few clicks

No typing needed. Pick your system; we've tried to select it for you.

  1. Double-click FastConnect-Setup-v1.1.exe

    You'll find it in your Downloads folder. Python and everything else the app needs is built in.

    If Windows shows "Windows protected your PC", click More info → Run anyway. This appears because the installer is new and not yet code-signed.

  2. Click Install

    Fast Connect installs for your account only, so no admin password is needed. Choose whether you want a Desktop shortcut.

  3. That's it

    Fast Connect starts automatically. Find it later in the Start Menu or on your Desktop. To remove it, go to Settings → Apps.

Troubleshooting

  • "Fast Connect is running" (Windows): close Fast Connect, then click Try again in the installer.
  • install.sh opens in a text editor (Linux): right-click it and choose Run as a Program. If that option is missing, open Properties → Permissions, tick Allow executing file as program, and try again.
  • Network errors: check your internet connection and run the installer again. It's safe to run more than once.
  • The shortcut stopped working (macOS / Linux): you probably moved the FastConnect folder. Run the installer again from its new location.
